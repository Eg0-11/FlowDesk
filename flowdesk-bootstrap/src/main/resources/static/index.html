FlowDesk 本机演示入口

这是供本机演示用的最小网页入口：主服务只监听 127.0.0.1， 没有鉴权，不要用于远程访问或生产环境。

首页 服务状态 工单列表 新建工单 工单详情 知识文档 后续页面：AI 研判（尚未实现）

首页

本页由主服务同源提供，页面里的所有接口请求都使用相对路径（/api/v1/...）。

  • 页面加载时只请求服务自身的健康端点；不发送任何写请求，也不调用知识检索或 AI 接口，因此不产生任何模型费用。
  • 工单列表、工单详情、新建工单都在你点击之后才发请求。
  • 当前阶段提供：列表（可翻页）、单条详情、新建工单，以及按真实状态可用的状态变更（分配 / 重新分配 / 开始处理 / 解决 / 关闭）；写请求只有在你点击操作之后才发出，且只使用单条详情的强 ETag 做并发控制。
  • 切换详情会立刻清空上一条件工单的操作区：新详情取不到（404、网络中断或响应格式异常）时不会对旧工单发出写请求；写请求前的预检如果发现版本与你看到的详情不一致（哪怕状态相同），本次操作会直接取消、一个写请求都不发。
  • 一旦出现版本漂移、状态变化、响应格式异常，或写请求得到不完整的成功响应，详情仍可阅读，但操作区会被锁住（按钮清空，连点也发不出写请求）；只有点「刷新详情」取得有效的单条详情响应后，才按新状态重建按钮。首次打开详情时若强 ETag 缺失、格式不符合后端规范，或与响应体版本不一致，同样只展示只读详情，不提供操作。
  • 知识文档区（上传 / 按 ID 查找 / 解析）同样只在点击后发请求；它不调用列表、索引、检索或 AI 接口，因此也不产生模型费用。

工单详情

点击列表里的「详情」按钮，或创建成功后的「打开详情」。

下面是按当前状态可用的操作（调用后端既有端点）。写请求的 If-Match 只使用单条详情响应头里的强 ETag，不使用列表里的版本号。 一旦出现版本漂移、状态变化、响应格式异常或不完整的成功响应， 详情仍然可读，但操作区会被清空并锁住：连点旧按钮也不会发出任何写请求。 只有点「刷新详情」取得有效的单条详情响应后，才会按新状态重建按钮。

知识文档

这里的逻辑由独立的 knowledge.js 负责，与工单脚本互不影响。 后端没有文档列表接口，所以本区只能「按 ID 查找」已知的文档， 不能列出全部文档；页面也不会伪称它能列出来。

浏览器端的提示只是方便你少走弯路，服务端始终是最终校验者：格式不符返回 415，超过上限返回 413。

上传文档

上传使用后端既有的 multipart（title + file）。成功时返回 201 与 Location，没有 ETag。

按 ID 查找

文档查询接口没有 ETag，因此下面的版本号只是本次查询的快照。

只有 UPLOADED / PARSE_FAILED 允许解析。点击「解析」时会 先重新查询，核对文档 ID、状态和你看到的版本，再由该版本构造带双引号的 If-Match（不会写死 "0"）。 版本不一致时本次写请求直接取消。解析成功后，响应头 ETag 必须与响应体版本一致， 页面按服务端返回的权威版本更新，不假定解析只加 1。

只有 PARSED / INDEX_FAILED 允许索引，且必须先勾选上面的费用确认。 页面加载、查询或解析成功时绝不会自动索引；确认后点击「索引」会先重新查询核对 文档 ID、状态与你看到的版本，再由当前版本构造带双引号的 If-Match， 最多发送一次索引写请求。版本不一致时本次写请求直接取消。 未启用 Embedding（Basic 模式）时索引会返回 503，此时文档不会被读取或修改。 网络中断、响应读不出来或服务端错误时结果无法确认，索引区会锁定并要求重新查询，不自动重试。
