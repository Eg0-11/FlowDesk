首页

本页由主服务同源提供，页面里的所有接口请求都使用相对路径（/api/v1/...）。

  • 页面加载时只请求服务自身的健康端点；不发送任何写请求，也不调用知识检索或 AI 接口，因此不产生任何模型费用。
  • 工单列表、工单详情、新建工单都在你点击之后才发请求。
  • 当前阶段提供：列表（可翻页）、单条详情、新建工单；不含分配、开始处理、解决、关闭等状态变更（留给下一小阶段）。
